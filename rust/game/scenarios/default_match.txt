# The default match (Slice 4f): a keyboard-driven, respawning, F5-restartable
# 2P-hotseat match in Mode::Live. Since Step 4½c the bare `cargo run -p game` starts
# like C++ NEW GAME instead (game::new_game: a generated level, a fresh seed, weapon
# selection); this fixture is what `--live --record <path> default_match` plays and
# records (a recording starts from a scenario), and the scenario-path test fixture.
#
# It is deliberately NOT one of the `render_slice3b_*` goldens: those are fixed
# recorded-input demos (Scripted), whereas the default match is played live. It
# lives outside `oracle-tests/golden/` on purpose, so it never appears in the
# `available_scenarios` help listing or any golden enumeration, and it needs no
# frame/state sidecar (Live loads no golden column and runs no self-check).
#
# Fixed level + fixed seed 42 — NO random level generation / GenerateFromSettings
# (a deferred, out-of-scope surface). Two worms on the shipped render_stage level,
# each with a full default loadout (slot 0 = DART).
# `ticks 0` / no `input` lines: both are unused in Live mode (the keyboard drives
# every tick); `ticks` is present only because the grammar requires it.
seed 42
level Levels/render_stage.lev

# `killed_timer <= 0` — so the camera never scrolled and a walking worm left the
