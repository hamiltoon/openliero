# === WHAT THIS PROVES: DrawLaserSight advances the per-viewport RNG ==================

# laserSight=true). In the sprite pass (viewport.cpp:500-516) a visible worm whose

# viewport's OWN Viewport::rand (default-seeded, one instance per viewport, state
# accumulates across ticks — NEVER game.rand). So even with a MOTIONLESS worm the spark
# pattern differs every tick because vp->rand advanced — the frame hash MOVES tick-to-tick.
