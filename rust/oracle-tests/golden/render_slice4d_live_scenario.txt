#     game.screen_flash=8 at sobject-create; the top-of-frame decrement walks it 8->0 over
#     the following 8 ticks. The palette LightUp blip changes EVERY pixel while flash>0 —
#     the flash-decay non-vacuity window (frame differs from the screen_flash=0 control).
#
#   * SHAKE (per-viewport, position-dependent): `large_explosion` (shake=4) emits a
#     (x,y,4) shake event; the game layer maxes viewports[vp].shake = itof(4) for every
#     viewport whose CURRENT window contains the blast. worm1 DIES ~tick 90 (health 12 <=

#     now-centred window [36,194) x [117,275) — so the blast sets vp1.shake LIVE. The
#     viewport-local RNG then jitters x/y for ~50 ticks (itof(4)=262144, -4000/tick until
#     Ftoi<1) — the shake-decay non-vacuity window (viewport (x,y) differs from a
#     centering-only re-render with shake zeroed).
#
#   * BANNER (per-viewport walk): worm1's death sets killed_timer=150; the dead-arm resets
#     banner_y=-8 at killed_timer==150, then the (cycles&1) every-other-cycle walk steps
#     banner_y toward +2 while killed_timer>16 (a death is showing) and back toward -8 as
#     the timer drains past 16 near respawn — banner_y reaches -8 then walks up then back.
#
#   * CENTERING (camera follows a LIVE worm): after the 150-tick countdown worm1 runs
#     BeginRespawn/DoRespawning (the 5d path: a Fire-to-latch `ready` at tick 150 while
#     dead), flips visible=true with killed_timer<=0, and DROPS to a new spawn — so the
#     alive-visible arm SetCenters and the camera MOVES as worm1 falls/settles (frame
#     changes tick-to-tick purely from the camera follow — the centering non-vacuity).
